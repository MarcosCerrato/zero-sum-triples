# Zero-sum triples in {±1,…,±m} ∖ {±b}

Lean 4 / Mathlib formalization and supporting code for the note
*"Zero-sum triples in {±1,…,±m} ∖ {±b}: the case 3 | b"* (Marcos Cerrato, 2026; source in `paper/`).

**Lemma B(m, b).** For m ≡ 1 (mod 3) and 1 ≤ b ≤ m, the set {±1,…,±m} ∖ {±b} can be partitioned into
triples with sum 0 (equivalently, [−m..m] splits into zero-sum triples one of which is {−b, 0, b}).

**Result.** Lemma B(m, b) holds for every m ≡ 1 (mod 3) and every b ∈ [1..m], except
(m, b) ∈ {(4,1), (4,3), (7,1)}. The new part is the case 3 | b; for m ≥ 10 the whole statement is
machine-checked:

```lean
theorem LemaB.lemmaB :
    ∀ m b : ℕ, m % 3 = 1 → 10 ≤ m → 1 ≤ b → b ≤ m → LemaB.LemmaB m b
-- #print axioms LemaB.lemmaB  ==>  [propext, Classical.choice, Quot.sound]
```

No `sorry`, no `native_decide`, no extra axioms. The cases m ≤ 7 were settled by exhaustive search.

## Building

Requires [elan](https://github.com/leanprover/elan). Toolchain `leanprover/lean4:v4.37.0-rc1`, Mathlib `v4.37.0-rc1`.

```sh
lake exe cache get   # prebuilt Mathlib
lake build           # ~15 min the first time (large decide-checked tables in GNLean)
```

## Layout

| Path | Content |
|---|---|
| `LemmaB/Defs.lean` | zero-sum triples, partitions (`ZS`, `IsPart`) |
| `LemmaB/Transfer.lean` | 3-adic transfer lemma with a (0,0,0) block; definition of `LemmaB` |
| `LemmaB/Runs.lean`, `Builder.lean` | runs of sum −1 and the X-system builder |
| `LemmaB/Families.lean` | the 17 affine families (generated by `python/gen_lean.py`) |
| `LemmaB/Cert.lean`, `Small.lean` | certificates for 10 ≤ m < 46 and (55,54), checked by `decide` (generated by `python/gen_certs.py`) |
| `LemmaB/Main.lean`, `Final.lean` | the induction; `lemmaB_of_not_dvd` (Lemma B assuming the case 3 ∤ b) |
| `LemmaB/GNLean/` | adapted copy of [gn-lean](https://github.com/JD-Jones-ASES/gn-lean) (MIT): displacement permutations for the case 3 ∤ b |
| `LemmaB/Unconditional.lean` | the case 3 ∤ b and the final theorem `lemmaB` |
| `python/` | independent verifier (`verify.py families`, `verify.py build M`) and the generators |
| `paper/` | LaTeX source of the note |

Comments in the Lean sources are partly in Spanish.
